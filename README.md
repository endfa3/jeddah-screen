# جدة — نافذتك اليومية

واجهة عربية داكنة للتلفزيون: الساعة والتاريخ، طقس جدة، أوقات الصلاة والعد التنازلي، مباريات مختارة، وعناوين التقنية. لا تحتاج إلى مفاتيح API. البيانات في الملف المرفق لقطة وقت الإعداد؛ يبدأ التحديث بعد نشر المشروع وتشغيل Actions.

## النشر على GitHub خطوة بخطوة

1. فك ضغط الملف. ثبّت GitHub Desktop من https://desktop.github.com وسجّل الدخول بحسابك.
2. من File → New repository أنشئ مستودعًا باسم `jeddah-screen`، ثم اختر Repository → Show in Explorer.
3. انسخ **محتويات** مجلد المشروع إلى مجلد المستودع، بحيث يظهر `index.html` مباشرة في جذره، وليس داخل مجلد إضافي. انسخ أيضًا `.github` و`scripts` و`data`. إن لم يظهر المجلد الذي يبدأ بنقطة فعّل إظهار الملفات المخفية.
4. في GitHub Desktop اكتب وصفًا مثل `Add Jeddah dashboard` ثم Commit to main، وبعدها Publish repository. ألغِ خيار Keep this code private لاستخدام GitHub Pages مع حساب GitHub Free. لا تضع بيانات شخصية في المستودع.
5. من صفحة المستودع على GitHub افتح Settings → Pages، وفي Source اختر **GitHub Actions**.
6. افتح Actions → Update and publish dashboard → Run workflow → Run workflow. إذا فشل التشغيل الأول قبل تفعيل Pages، أعد تشغيله بعد الخطوة السابقة.
7. انتظر علامة النجاح الخضراء. افتح الرابط الذي يظهر في Settings → Pages. شكله `https://USERNAME.github.io/jeddah-screen/` مع استبدال USERNAME باسم حسابك الفعلي.
8. التحديث مجدول في الدقيقتين 7 و37 من كل ساعة؛ الصفحة تقرأ البيانات كل دقيقة. قد يتأخر تشغيل GitHub المجدول، والنتائج ليست لحظية. قد توقف GitHub الجداول في المستودعات العامة بعد 60 يومًا من عدم النشاط؛ أعد تفعيلها من Actions عند الحاجة.

يمكن الرفع من المتصفح أيضًا، لكن يجب التأكد من وجود الملف `.github/workflows/update.yml`؛ رفع index.html وحده لا يفعّل البيانات. لا ترفع ZIP كما هو: GitHub لا يفك ضغطه للنشر.

## التشغيل على TCL بنظام Google TV / Android TV

1. افتح متجر التطبيقات على التلفزيون وابحث عن **TV Bro**. تحقّق أن التطبيق من المطوّر المرتبط بالمشروع الرسمي https://github.com/truefedex/tv-bro . قد يختلف توفره حسب الجهاز والمنطقة.
2. افتح رابط GitHub Pages في المتصفح، واحفظه في المفضلة.
3. اضغط «ملء الشاشة» في أعلى التصميم. إذا لم يدعمه المتصفح، استخدم خيار ملء الشاشة الخاص به إن توفر.
4. اترك الصفحة مفتوحة. إذا تدخل مؤقت السكون، راجع إعدادات الشاشة للطاقة والخمول واختر المدة المناسبة؛ تختلف أسماء القوائم حسب الموديل. محاولة إبقاء الشاشة مستيقظة داخل الموقع تعتمد على دعم المتصفح.
5. اضغط رجوع للخروج. إذا قُصّت الحواف، اختر وضع ملاءمة الصورة/Just Scan من إعدادات الصورة إن توفر.

**التمييز المهم:** هذه لوحة ويب تُفتح في المتصفح. لا تتحول تلقائيًا إلى شاشة توقف للنظام بمجرد نشرها. Ambient Mode الافتراضي لا يوفر طريقة معتادة لإضافة رابط لوحة ويب. التشغيل عند خمول التلفزيون أو عند الإقلاع يحتاج تطبيقًا متوافقًا ونظامًا يسمح بذلك؛ لم يُختبر هذا على جهازك. يمكن تجربة تطبيق kiosk موثوق يدعم طرازك، لكن لا تفترض أن تثبيته وحده يجعله شاشة توقف للنظام.

**بديل مباشر:** افتح الرابط على كمبيوتر موصول بالتلفزيون عبر HDMI واضغط F11، واضبط سكون الكمبيوتر للمدة المطلوبة.

## البيانات وحدودها

- الطقس: Open-Meteo، إحداثيات وسط جدة، استخدام شخصي غير تجاري. https://open-meteo.com/
- الصلاة: AlAdhan بطريقة أم القرى (4)، المنطقة الزمنية السعودية. هذه أوقات حسابية، قارِنها بتقويم مسجدك المحلي. https://aladhan.com/prayer-times-api
- المباريات: تغطية ESPN للدوري السعودي والإنجليزي والإسباني وأبطال أوروبا. ليست كل مباريات العالم. المصدر غير موثق كواجهة عامة مضمونة وقد يتغير أو يتوقف. بعض أسماء الفرق غير الموجودة في قاموس التعريب تظهر بلغة المصدر؛ يمكن إضافة ترجمتها في `TEAMS` داخل `scripts/update.py`.
- الأخبار: عناوين وروابط RSS من عالم التقنية والبوابة التقنية، دون نسخ المقالات كاملة. تتبدل الصفحات كل 15 ثانية.
- كل قسم يبين وقت تحديثه، وتظهر علامة «بيانات قديمة» بعد ساعتين. عند اختلاف تاريخ الصلاة أو المباريات عن يوم جدة تُخفى البيانات القديمة. لا تُستخدم بيانات وهمية.
- تحديثات Actions لا تُحفظ كالتزامات في المستودع؛ تُنشر مباشرة إلى Pages. عند تعطل المصدر في تشغيل لاحق، قد تكون النسخة الاحتياطية هي لقطة البيانات الموجودة أصلًا في المستودع، ويظهر تاريخها/تنبيه قدمها.
- يعتمد الخط على Google Fonts مع بديل Arial إذا تعذّر تحميله.

## التحقق أثناء الإعداد

فُحصت صياغة JavaScript وشُغّل مجمّع البيانات. تعذّر إكمال المعاينة البصرية داخل متصفح بيئة العمل بسبب انتهاء مهلة الاتصال بالخادم المحلي؛ يلزم فحص العرض على تلفزيونك بعد النشر. لم يُنشر المشروع في حسابك على GitHub من هذه المحادثة.
